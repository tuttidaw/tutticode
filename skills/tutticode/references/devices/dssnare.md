# DS Snare

An instrument (`.inst`), available.

```js
note("c3 e3 g3 b3").inst("DS Snare")
```

Accepted names: `dssnare`.

## Parameters

| Key | Live label | Values |
|---|---|---|
| `colorAmount` | Color | 0 .. 100 |
| `decay` | Decay | 0 .. 100 |
| `tone` | Tone | 0 .. 100 |
| `tune` | Tune | 0 .. 100 |
| `volume` | Volume | -70 .. 12 dB |
