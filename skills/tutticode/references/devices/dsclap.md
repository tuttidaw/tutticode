# Clap Synth

An instrument (`.inst`), available.

```js
note("c3 e3 g3 b3").inst("Clap Synth")
```

Accepted names: `clapsynth`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `decay` | Decay | 0 .. 100 |
| `sloppy` | Sloppy | 0 .. 100 |
| `spread` | Spread | 0 .. 100 |
| `tail` | Tail | 0 .. 100 |
| `tone` | Tone | 0 .. 100 |
| `tune` | Tune | 0 .. 100 |
| `volume` | Volume | -70 .. 18 dB |
