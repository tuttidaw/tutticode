# Amp

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Amp:Bass Roundup")
```

Accepted names: `amp`.

## Parameters

| Key | Live label | Values |
|---|---|---|
| `drive` | Gain | 0 .. 10 |
| `bass` | Bass | 0 .. 10 |
| `middle` | Middle | 0 .. 10 |
| `treble` | Treble | 0 .. 10 |
| `presence` | Presence | 0 .. 10 |
| `volume` | Volume | 0 .. 10 |
| `dryWetBalance` | Dry/Wet | 0 .. 1 % |
