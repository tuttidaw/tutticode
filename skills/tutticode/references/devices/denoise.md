# Denoise

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Denoise:Full Suppression")
```

Accepted names: `denoise`.

## Parameters

| Key | Live label | Values |
|---|---|---|
| `reduction` | Reduction | 0 .. 100 dB |

## Factory presets

Full Suppression · Gentle Room Tone · Home Studio Voice · Noisy Location
