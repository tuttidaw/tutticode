# Noise Distortion

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Noise Distortion:Gritty Mids")
```

Accepted names: `noisedistortion`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `mode` | Mode | `Noise` `Wide Noise` `Sine` |
| `frequency` | Freq | 300 .. 18000 Hz (log) |
| `amount` | Amount | 0 .. 1 |
| `width` | Width | 0.1 .. 2.5 |

## Factory presets

Gritty Mids · Lo-Fi Sheen · Sine Ring
