# Cabinet

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Cabinet:1x12 Cab")
```

Accepted names: `cabinet`.

## Parameters

| Key | Live label | Values |
|---|---|---|
| `dryWetBalance` | Dry/Wet | 0 .. 1 % |
