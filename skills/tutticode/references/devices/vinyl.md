# Vinyl Wear

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Vinyl Wear:Clean Press")
```

Accepted names: `vinylwear`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `tracingDrive` | Tracing Drive | 0 .. 1 |
| `tracingFreq` | Tracing Freq | 50 .. 18000 Hz (log) |
| `tracingWidth` | Tracing Width | 0.1 .. 3 |
| `pinchDrive` | Pinch Drive | 0 .. 1 |
| `pinchFreq` | Pinch Freq | 50 .. 18000 Hz (log) |
| `pinchWidth` | Pinch Width | 0.1 .. 3 |
| `globalDrive` | Global Drive | 0 .. 1 |
| `crackleDensity` | Crackle Density | 0 .. 1 |
| `crackleVolume` | Crackle Volume | 0 .. 1 |
| `tracingOn` | Tracing On | `true` / `false` |
| `pinchOn` | Pinch On | `true` / `false` |
| `pinchSoftOn` | Pinch Soft | `true` / `false` |
| `pinchMonoOn` | Pinch Mono | `true` / `false` |

## Factory presets

Clean Press · Dusty Groove · Pinched Highs · Worn 45
