# Basic Synth

An instrument (`.inst`), available.

```js
note("c3 e3 g3 b3").inst("Basic Synth:Bass Sub Round")
```

Accepted names: `basicsynth`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `oscMix` | Osc Mix | 0 .. 1 % |
| `osc2Detune` | Detune | -1200 .. 1200 ct |
| `cutoff` | Cutoff | 20 .. 20000 Hz (log) |
| `resonance` | Resonance | 0 .. 1 % |
| `filterEnv` | Filter Env | -4 .. 4 oct |
| `attack` | Attack | 1 .. 2000 ms (log) |
| `decay` | Decay | 1 .. 5000 ms (log) |
| `sustain` | Sustain | 0 .. 1 % |
| `release` | Release | 1 .. 5000 ms (log) |
| `volume` | Volume | 0 .. 1 % |
