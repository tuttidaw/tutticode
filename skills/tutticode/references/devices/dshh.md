# Hat Synth

An instrument (`.inst`), available.

```js
note("c3 e3 g3 b3").inst("Hat Synth")
```

Accepted names: `hatsynth`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `attack` | Attack | 0 .. 100 |
| `decay` | Decay | 0 .. 100 |
| `pitch` | Pitch | 0 .. 100 |
| `tone` | Tone | 0 .. 100 |
| `volume` | Volume | -70 .. 18 dB |

None.
