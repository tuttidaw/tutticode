# FM Drum

An instrument (`.inst`), available.

```js
note("c3 e3 g3 b3").inst("FM Drum")
```

Accepted names: `fmdrum`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `amount` | Amount | 0 .. 100 |
| `decay` | Decay | 0 .. 100 |
| `feedback` | Feedb. | 0 .. 100 |
| `modulation` | Mod | 0 .. 100 |
| `pitch` | Pitch | 12 .. 127 |
| `tone` | Tone | 0 .. 100 |
| `volume` | Volume | -70 .. 6 dB |

## Factory presets

None.
