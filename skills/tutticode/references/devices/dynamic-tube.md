# Tube Drive

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Tube Drive:Hot Tube")
```

Accepted names: `tubedrive`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `drive` | Drive | -15 .. 15 dB |
| `tone` | Tone | -1 .. 1 |
| `bias` | Bias | 0 .. 1 |
| `envelope` | Envelope | -3 .. 3 |
| `attack` | Attack | 1 .. 400 ms (log) |
| `release` | Release | 1 .. 1500 ms (log) |
| `output` | Output | -15 .. 15 dB |
| `dryWetBalance` | Dry/Wet | 0 .. 1 |

## Factory presets
