# Hybrid Reverb

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Hybrid Reverb:Cathedral")
```

Accepted names: `hybridreverb`.

## Parameters

| Key | Live label | Values |
|---|---|---|
| `preDelay` | Predelay | 0 .. 250 ms |
| `dryWetBalance` | Dry/Wet | 0 .. 1 |
| `freeze` | Freeze | `true` / `false` |
| `freezeIn` | Freeze In | `true` / `false` |

## Factory presets

Cathedral · Concert Hall · Drum Room · Spring Tank · Tight Ambience · Vintage Plate
