# Align Delay

An audio effect (`.fx`), available.

```js
note("c3 e3 g3 b3").fx("Align Delay:A/V Sync 40ms")
```

Accepted names: `aligndelay`.

## Parameters

| Key | Live label | Values |
|---|---|---|
| `delayMsL` | Left ms | 0 .. 100 ms |
| `delayMsR` | Right ms | 0 .. 100 ms |
| `samplesL` | Left samples | 0 .. 200 smp |
| `samplesR` | Right samples | 0 .. 200 smp |
| `metersL` | Left meter | 0 .. 100 m |
| `metersR` | Right meter | 0 .. 100 m |
| `feetL` | Left Feet | 0 .. 328.08 ft |
| `feetR` | Right Feet | 0 .. 328.08 ft |
| `celsius` | Celsius | -20 .. 60 °C |
| `fahrenheit` | Fahrenheit | -4 .. 140 °F |

## Factory presets

A/V Sync 40ms · Distance Trim · Haas Widener · Sample Compensate
