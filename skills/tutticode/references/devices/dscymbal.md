# Cymbal Synth

An instrument (`.inst`), available.

```js
note("c3 e3 g3 b3").inst("Cymbal Synth")
```

Accepted names: `cymbalsynth`.

## Parameters

| Key | Panel label | Values |
|---|---|---|
| `decay` | Decay | 0 .. 100 |
| `pitch` | Pitch | 0 .. 100 |
| `tone` | Tone | 0 .. 100 |
| `volume` | Volume | -70 .. 6 dB |

## Factory presets

None.
